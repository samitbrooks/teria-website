# **App Name**: TERIA Homepage Hero

## Core Features:

- Headline: Displays a bold heading conveying the organization's mission: Empowering Communities for a Better Tomorrow.
- Mission Statement: Includes a concise paragraph summarizing TERIA's mission and goals.
- Background Image: Features a background image placeholder that can be replaced with a relevant visual.
- Call to Action Buttons: Includes 'Get Involved' and 'Our Work' buttons to drive user engagement and navigation.
- Responsive Layout: Implements a responsive design to ensure the hero section adapts to various screen sizes.

## Style Guidelines:

- Primary color: Deep teal (#008080) to convey trust, stability, and growth, fitting for a nonprofit focused on empowerment and inclusion.
- Background color: Very light teal (#E0F8F8) to provide a subtle and clean backdrop that complements the primary color without overwhelming the content.
- Accent color: Soft coral (#F08080) to draw attention to key interactive elements like buttons, providing a warm and inviting contrast to the teal palette.
- Headline font: 'Poppins' (sans-serif) for a modern and accessible feel.
- Body font: 'PT Sans' (sans-serif), complementing 'Poppins,' which provides good readability.
- The hero section will occupy the full viewport width on larger screens, with a maximum height to maintain balance. On smaller screens, elements stack vertically for optimal viewing.
- Simple, clean icons will be used sparingly to enhance the message of the 'Get Involved' and 'Our Work' buttons.
- Subtle fade-in animations upon page load to create a welcoming and engaging user experience.
